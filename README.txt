[여는 법]
index.html 을 크롬/엣지로 엽니다. photos 폴더는 index.html 과 같은 폴더에 두어야 사진이 보입니다.
(글꼴만 인터넷에서 불러오므로, 오프라인이면 기본 글꼴로 보입니다.)

[발표]
오른쪽 위 '발표 모드' 또는 P 키 → 전체 화면.  → / 스페이스: 다음,  ← : 이전,  Esc: 끝내기
사진이나 카드를 누르면 크게 보기(← → 로 넘김, Esc 로 닫기).

[고치기]
index.html 을 메모장/VS Code로 열고 위쪽 WORKSHOPS / PROVINCE / TOGETHER 목록의 글을 고치면 됩니다.
사진을 추가하려면 photos 폴더에 '키-번호.jpg'로 넣고 PHOTOS 의 개수를 늘립니다.
  예) 4차 빛 탐구 사진 5번째 → photos/light4-4.jpg, PHOTOS 의 light4 를 5로.
8차(11월 24일)는 계획(천체 관측·원소기호 LED 키캡·반려식물)을 담은 '예정' 슬라이드입니다.
워크숍이 끝나면 WORKSHOPS 의 8차 항목에서 upcoming:true 를 지우고, 사진을 photos 폴더에 넣으세요.
  예) 천체 관측 사진 → photos/scope-0.jpg 로 넣고, 8차 천체 관측 항목에 ph:"scope" 를, PHOTOS 에 "scope": 장수 를 추가.
